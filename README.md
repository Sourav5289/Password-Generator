🔐 Password Generator is a Python-based tool designed to create strong and secure passwords by combining letters, numbers, and symbols.<br>
💡 It allows users to choose how many of each character type they want, ensuring complete customization.<br>
🎲 The program uses Python’s random module to generate unpredictable and unique passwords every time.<br>
⚙️ Simple, efficient, and beginner-friendly — perfect for enhancing cybersecurity and learning randomization concepts.
